# 原生物品槽位编辑

掉落物与普通 / 荧光展示框的 Item 已接入同一槽位面板，使用一个不带 Slot 的完整 Compound，支持已有物品操作及完整 NBT。对象窗口显示“物品 / NBT”两页，编辑继续通过原对象的预检、暂存与世界历史。此新增路径待完整迁移完成后统一验证。

## 实体装备

动物实际保存的 ArmorItem、DecorItem 和 SaddleItem 单物品字段也进入同一装备页，分别显示动物护甲、装饰和鞍具；1.21.1 身体装备使用 body_armor_item。保留完整物品 Compound、版本与真实源路径，复用原有编辑 / 撤销 / 保存。三版狼及现代马类 / 羊驼的相应静态显示已接入世界和结构预览，旧马类 / 羊驼和其他动物继续迁移，全部新增路径待最终统一验证。

源实体实际保存 ArmorItems、HandItems 或 body_armor_item 时，Inspector 提供装备与 NBT 两页。护甲按头盔、胸甲、护腿、靴子显示，双手按主手、副手显示；前两者的保存位置分别是四项和两项固定 Compound 列表，不以 Slot 字段定位。身体装备使用 1.21.1 的单个完整 Compound。没有实际装备字段的未知实体不按 ID 臆造容量。

固定列表的空位置保留空 Compound，删除不会把下一件装备推到错误部位；交换完整项、填充短列表及清空仍保持实际容量。复制 / 剪切 / 粘贴、预设、数量 / 耐久、完整 NBT、跨库存移动与一次文档撤销复用现有入口。玩家装备继续使用已有 Inventory 布局；统一源解析按 SelectedItemSlot 读取当前主手，保留副手和四件护甲的真实存储索引。第三人称手持物、四件护甲、皮革染色 / 覆盖层、真实纹饰及组合动画已接入世界与结构预览；头部槽使用实际头盔或通用 head 资源 / 专用头颅，胸部鞘翅使用真实保存姿态和实际装饰纹理。所有新增路径未编译、测试或进行窗口验收，动物装备和其他实体继续迁移，待最后统一验证。

## 原版依据与当前范围

布局直接对应原版 `7c13c16^:src/mcedit2/panels/player.py` 的装备、三排主背包和快捷栏，以及 `widgets/inspector/tileentities/chest.py` 的箱子 27 格、发射器 3×3 和漏斗 5 格。另接入已有的玩家末影箱与副手槽。玩家文件和世界对象共用界面与核心操作，文档历史、对象预检、候选渲染和保存继续走各自现有入口。

当前格子显示槽号、真实资源图标和数量，悬停保留名称 / ID 与图标诊断；整组横向滚动保持列对齐，选择后编辑完整 ID、数量及存在的旧版耐久。搜索选择器按准确数据版本列出物品、名称和旧 metadata 变体，分页选择只更新草稿，点击应用才写入。容器已扩展至下列准确版本的原生布局；真实窗口验收仍未完成。

## 操作与数据

- 应用物品字段、空槽新建、复制 / 剪切 / 粘贴、删除和清空库存；高级 NBT 保留完整标签与组件入口。
- 选择来源后点击目标槽，在同一文档内移动 / 交换，也可跨玩家背包和末影箱；一次操作只有一条文档撤销。另保留直接输入目标槽的操作。
- 冻结物品剪贴板跨玩家文件和容器使用，复制允许只读。剪切成功修改所属文档后才发布剪贴板；世界对象仍须预检及确认暂存，文件仍须准备及确认保存。
- 新建物品核对准确数据版本：1343 使用 String id、Byte Count 与 Short Damage；3465 使用 String id 和 Byte Count；3955 使用 String id 和 Int count。已有旧数字 Short id 可按实际字段编辑；未核实的版本不创建新编码，不进行跨版本转换。数字及未知版本物品只在原世界使用。
- 修改已有物品时只补丁修改相应字段，带 Slot 的同库存移动只改 Slot，删除只移除对应列表项；固定装备列表则交换完整项或将对应项置为空 Compound。未参与操作的物品及未修改字段保留原字节；跨库存移动和剪贴板保留整个物品 Compound 的值、tag、components 和未知字段。
- 战利品容器明确选择“改为手动物品”后才移除 LootTable 及其 Seed，不执行或猜测游戏的战利品生成。

## 来源与界面状态

每份 NBT 文档有独立世代；成功修改、撤销与重做更新身份，失败保持原身份，克隆在修改前共享身份。槽位按钮绑定实际文档快照，表单绑定独立选择令牌，文件 / 对象切换和历史操作后的旧事件不能落到新物品。界面快照按文档世代复用，不在每帧复制完整玩家根节点；可选库存字段通过具体字段读取，与字段错误和缺失分开处理。

只读、保存任务和待确认文件候选沿用当前文档的操作条件。错误正常传播和报告；不丢弃损坏库存项、不猜槽位容量，也不自动修复物品或转换版本。

## 图标与物品目录

内置目录分别从官方 1.12.2 / 1.20.1 / 1.21.1 的公开注册表导出，包含名称键、堆叠 / 耐久上限及默认物品着色。1.12.2 通过原版 RenderItem 的受保护注册钩子和真实动态模型查询导出 metadata、模型名和变体名称 / 着色，不使用反射、不构造游戏窗口或世界。`tools/generate_item_registry.py` 校验客户端 SHA1，临时分析副本只移除签名文件，逐成员校验一致后使用；所有临时类和副本自动删除。只对已核实的 1343 / 3465 / 3955 提供目录，未知与模组物品仍可直接输入实际 ID。

生产资源索引保留 `models/item/` 根模型、父模型、覆盖子模型和依赖纹理，同样计入现有预算。图标读取实际资源包优先级、生成式 layer0–4、Alpha 边缘薄片、普通模型元素 / 元素旋转 / 默认 UV / UV 旋转、GUI 显示变换及 gui_light；声明式独立变换选择 GUI 分支，既有 OBJ 三角形保留顶点色与材质。复用实际图集和 Canvas 深度、Alpha 阈值及透明通道，生成 32×32 图片。普通 damage / damaged / custom_model_data 覆盖只使用真实物品值，缺少世界和持有者上下文的属性不编造。

槽位与选择器使用同一后台缓存，按不可变资源身份和外观参数复用，最多保留 512 个图标；资源替换取消旧来源并唤醒当前视图。只有近期显示的动画图标继续更新，静态图标不创建持续任务。支持旧 tag / 新组件的耐久、自定义模型值、皮甲颜色及显式药水 / 地图颜色。完整物品载荷继续只读，不因显示修改数据。

已接入原版 builtin/entity 物品：箱子 / 陷阱箱 / 末影箱、各色床 / 潜影盒 / 旗帜、盾牌、全部头颅、潮涌核心和饰纹陶罐。旗帜 / 盾牌读取实际图案与底色，陶罐按后 / 左 / 右 / 前的真实装饰绘制，玩家头颅读取原有本地皮肤缓存；图标使用统一的在线皮肤开关，默认离线；启用时复用现有 Mojang 解析与本地缓存。1.12.2 床 / 旗帜的 16 色变体来自实际创造栏与动态模型查询。

尚未完成：持有者 / 世界驱动属性、未知模组物品注册行为和真实窗口 / 游戏对照。缺少准确模型、纹理或着色时给出具体诊断，不用同名 PNG 或通用方块替代。当前离屏像素验证不能替代真实窗口布局、DPI 和游戏内显示验收。

## 专用模型依据

原版物品模型父链仍负责 GUI display / gui_light 和覆盖选择；只有最终落到 builtin/entity 时才按原物品进入专用绘制，不接管资源包提供的普通 JSON 模型。无世界的箱子 / 床 / 潜影盒、旗帜 / 头颅 / 盾牌、未激活潮涌核心和陶罐使用其实际物品姿态。ModelPart 四角与 UV 复用公开模型层；旧箱子使用现有准确旧版元素配方。`tools/ItemSpecialReference.java` 与 `generate_item_special_reference.py` 通过公开 ModelPart.visit / Cube.compile 生成整组顶点参照，不创建图形窗口。1.20.1 的 16 个专用层经准确客户端逐字段对照，与共享层一致，只有校验证明被保留，没有复制同一套模型数据。

图标缓存键加入实际影响外观的组件 / tag；不复制容器 Items 或无关载荷。图案合成复用旗帜管线，缓存区分旗帜和盾牌材质；运行时贴图只追加到兼容图集，失败正常报告。库存数据仍不因显示而改变。

## 完整物品预设与动态颜色

选择器读取准确 1.12.2 / 1.20.1 / 1.21.1 默认物品和完整创造栏，共 918 / 1596 / 1726 个去重的原始 NBT 预设；旧版额外保留已注册 metadata。药水、附魔书、刷怪蛋、画、乐器等携带完整 tag 或 components；默认物品与创造栏版本可能不同，不按 ID 合并。名称和提示保留原版组件并通过当前资源语言表展开；旧版只把能唯一对应原语言表的字面文字转换为翻译组件，其余保留原文。

选择只更新草稿，可取消；应用替换该槽完整载荷，ID / 数量 / 旧 Damage 使用与普通编辑共享的字段修改规则。完整数据经既有库存事务提交为一次撤销；只读、文档世代、目标版本和战利品表限制保持有效。复制粘贴和未选择预设时的字段修改继续保留原有未知字段。选择器直接显示同名物品的前两行差异，悬停可读完整提示。

药水使用对应版本的效果注册颜色、基础药水、等级和粒子开关计算，旧版浮点混色与新版整数混色分别实现；显式颜色优先。烟火之星读取实际颜色数组，地图 / 皮革读取真实颜色，旧刷怪蛋读取 EntityTag。现代刷怪蛋沿用对应物品的固定提供器颜色。损坏类型或未知注册项正常报告；旧版原生提供器对显式空烟火颜色数组会除零，此处将它作为无效载荷报告。

`tools/generate_item_presets.py` / `ItemPresetReference.java` 调用准确客户端公开 API，现代版本从内置资源加载实际注册数据和标签，不伪造标签绑定，不创建世界或窗口。1.12.2 排除需要玩家客户端上下文的自定义快捷栏和库存页。临时分析副本、编译类与资源日志随生成目录删除；只保留 JSON 和校验摘要。另随同导出原版提供器对自定义混色等整组结果，用于现有资源类别的语料对照。

## 附魔光效与无世界物品属性

默认物品、创造栏及自定义外观参照均记录准确客户端的 hasFoil 和无世界属性提供器结果。光效读取真实附魔 / 覆盖组件，保留旧药水、金苹果及固定发光物品的原版分支。普通物品使用实际附魔 PNG、原版 TextureMat 时序和 SRC_COLOR / ONE 合成；旧版为双通道，新版采用默认速度 / 强度。光效使用当前图集 UV，与底图共用三角形覆盖和 EQUAL 深度，不写 Alpha，不在镂空或后方重复叠加。专用 BE 路径不自动继承普通光效，现代盾牌按原版显式使用物品光效。

图标缓存同时跟踪实际纹理帧和光效帧；只有近期显示的动画继续工作，支持没有 PNG 动画的独立光效时钟。在线皮肤开关改变时取消旧图标世代并重建；普通物品外观键不受皮肤策略值影响。选择器缓存查询结果，光效刷新不会逐帧重新遍历整个预设清单。

装填弩 / 烟火弹、鞘翅 broken、收纳袋实际内容重量、光源方块 level、现代盔甲 trim_type，以及实际耐久 / 不可破坏与自定义模型值进入原模型覆盖规则。保留无持有者的原版属性结果，不编造时钟、指南针或持有状态。1.20.1 的 trim_type 依赖世界注册表，当前无世界入口按其真实提供器返回值处理；1.21.1 使用实际材料组件。

资源加载解析 atlas 的 paletted_permutations，使用覆盖后的基础图、键图和值图生成纹饰，保留 Alpha、完整动画源与时序。定义展开和像素生成均计入既有工作预算；缺少来源或调色板长度不符正常报告。其他 atlas 来源类型仍沿用现有资源发现能力，尚未宣称实现任意 atlas 扩展。

## 原生容器属性与状态联动

原版 MCEdit2 的三类专用容器之外，按准确 1343 / 3465 / 3955 客户端的公开方块实体构造、Container 容量和保存 API 接入：箱子 / 陷阱箱 / 木桶 / 潜影盒、发射器 / 投掷器、漏斗、熔炉 / 高炉 / 烟熏炉、酿造台、营火、雕纹书架、合成器、唱片机、讲台、可疑方块与 1.21.1 饰纹陶罐。1.20.1 陶罐没有库存，不显示物品页；末影箱的内容仍属于玩家文件。熔炉和酿造台的位置依据准确客户端菜单字节码，其余采用各自容量的网格。空白不捕获槽位点击。

列表与 RecordItem / Book / item 单物品 Compound 共享完整物品编辑、剪贴板、移动、清空和文档历史；单物品不写入 Slot。1.20.1 可疑方块清空使用原版空物品编码，其他单物品按其保存字段删除。战利品表继续先显式转为手动物品。合成器可禁用空槽，禁用目标不能接受写入或交换。

对象面板提供属性 / 物品 / NBT 标签。属性按真实版本的 Byte / Short / Int / Long / IntArray 编辑燃烧、烹饪、酿造、传输、书页、合成和播放保存值；只有实际 BaseContainer 才提供名称与锁。名称的未修改文字保留原组件样式，明确改名才生成新文字组件。草稿修改不产生历史，应用全部属性为一次文档撤销；不模拟游戏运行。

雕纹书架六个占用属性、讲台 has_book 和唱片机 has_record / 旧 metadata 随真实物品字段变化，通过既有结构事务与完整方块实体一起暂存、撤销重做和保存。未修改的其他状态和不透明字段保留。旧版方块联动保存沿用原有光照合同；不绕过派生数据处理。未知版本仍可使用通用 NBT，未核实的原生专用编码不套用其他版本。

容量和空载荷记录由 tools/generate_container_reference.py 生成，校验准确客户端 SHA1、临时分析副本的逐成员一致性及最终数据摘要；不创建世界、窗口，不使用反射。1343 仅导出八类实际容器；现代从全部公开方块工厂导出并筛选支持的容器。集中验证接入原有 NBT、后台和导航类别，入口不增加；结果和当前限制见 PROGRESS.md。
