## 运行

大笔画行为并入世界的源会话 / BE、交换 / 编辑，以及桌面的渲染、后台和导航类别。使用真实编码的 32768 格旧数字 / 现代区块，覆盖预算拒绝、准备及提交中途取消、后段源变化、空心并集、多规则非连锁、连通填充、整组撤销重做和 512 个现代 biome 四格单元；逐段比较未知 NBT，并确认原 region 字节不变。桌面通过正式后台任务生成完整候选再暂存，材质光标继续使用真实资源模型。这些验证不代替真实窗口大笔画、真实存档性能或游戏保存重载验收。

在 `rust/` 下执行：

```sh
cargo test --workspace
cargo test --workspace -- --list
cargo clippy --workspace --all-targets -- -D warnings
```

配置好本机环境后，整组 GPU 验收使用一个入口，组内顺序执行实际材质、几何、透明深度和像素回读：

```sh

```

GPU 类别需要 `MCEDIT2_CLIENT_JAR` 和 `MCEDIT2_TEST_WORLD`。GPU 类别中的大型资源加载可用 `MCEDIT2_TEST_RESOURCE_MIB` 指定测试进程的资源预算，例如 `4096` 表示 4 GiB。它不修改桌面的预算设置。其他两个环境类别分别为 `installed_instance_resources_and_mesh`、`installed_framework_models`；后者还需要 `MCEDIT2_FRAMEWORK_JAR` 指向准确版本的安装文件。

主三维位置图层的读取、旧 / 新实体存储、乘客树、计划更新、投影 / 射线及取消交接流程均放在已有类别内。本机实例类别另读取真实主世界中心 9 个区块，报告各类标记数量，结果写入 `target/scene-layer-instance-profile.json`；该数据验收不代表定位框的桌面显示已经人工确认。

$env:MCEDIT2_MESH_RADIUS = '8'

## 维护约定

- 桌面和世界内核的入口分别位于对应 crate 的 `src/test_categories.rs`；集成测试的入口在各自测试文件末尾。模块中的 `run_test_category` 将实际行为检查接入对应类别。
- 新功能优先使用现有类别做必要的完整行为验证。只在出现独立功能域时增加类别，整体仍保持在 10–30 个入口内。
- 删除功能时，同步删除仅服务于它的检查和测试专用实现。不要增加确认功能已删除或未重新出现的回归测试。
- 不以源码字符串、按钮文案、枚举轮换、Debug 输出或单纯结构大小作为独立测试。关键验证直接调用生产逻辑，覆盖源读写、事务恢复、资源解释、插件边界和实际绘制结果。
- 类别内部检查失败就使整类失败，保留原始断言位置和错误信息；不吞掉异常继续报绿。

测试通过只证明这些类别中执行的场景；真实游戏保存重载、更多设备、桌面交互及完整迁移状态仍按 `MIGRATION.md`、`PROGRESS.md` 记录。

原生窗口回放：设置 `MCEDIT2_NATIVE_PROFILE` 为绝对 JSON 输出路径，以 `mcedit2 -view <一个存档>` 启动。完整源与实际显示世代一致后，聚焦窗口预热 1 秒，再依次旋转、飞行各 3 秒，自动导出并关闭。测量期间输入或失焦会中止；提交记录包含取帧等待、渲染提交、呈现调用、主线程与世界准备耗时，以及实际绘制/上传计数。该间隔是窗口提交节奏，不是 GPU 完成或屏幕显示耗时。使用单独的 `XDG_CONFIG_HOME` 隔离回放视图设置。

同一原生回放可设置 `MCEDIT2_NATIVE_PROFILE_WINDOW=1600x900`、`MCEDIT2_NATIVE_PROFILE_SCALE=1.5` 验收大窗口与缩放；窗口参数按系统逻辑单位指定，实际像素以记录为准。输出同时记录窗口、控件逻辑尺寸和实际栅格尺寸。`MCEDIT2_NATIVE_PROFILE_REVIEW_SECONDS=10` 只在成功记录后保留最终画面供集中截图，输入或失焦即退出，最长 30 秒；默认仍立即关闭。现有 GPU 类别覆盖 1/1.25/1.5/2 倍缩放的材质、深度、透视源拾取和正交 CPU/GPU 像素对照，不增加入口。
