# 连续笔刷

各世界投影、限定窗口、俯视、水平 / 垂直切片及四视图共用同一套笔画。启用后左键拖动，松开构建完整候选；审核候选后暂存，整条笔画作为一次撤销或重做。失焦、离开画布、鼠标导航或 Esc 取消尚未提交的笔画；Alt / Ctrl 保留原视图的点选操作。

## 形状与空心

尺寸按 X,Y,Z 输入，偏移沿命中面的法线计算。形状先应用到各个笔触，再合并为整条笔画的并集。“只画整条笔画并集的外壳”保留并集中至少一个六邻面暴露的格子，重叠笔触的内部不会留下隔板；它独立于空心盒、椭球壳等已有形状选项。

Biome 修改继续遵守真实存储单元：旧二维容器改变整列，三维容器改变触及的完整 4×4×4 单元。空心选择在投影到这些存储单元之前计算，因此底面或顶面仍可能触及二维范围内的所有列。

## 多条替换规则

每行指定一个目标和一个或多个完整源状态；多个源状态用 `|` 分隔。匹配使用当前会话中实际修改前的状态，包括已有暂存。相同源状态由最后一条规则决定，替换后的结果不会再参与同一笔画后面的规则。

| 源状态 | 目标状态 |
| --- | --- |
| `minecraft:stone \| minecraft:andesite` | `minecraft:dirt` |
| `minecraft:stone` | `minecraft:gold_block` |
| `minecraft:gold_block` | `minecraft:oak_log[axis=y]` |

这组规则把原石头改为金块、原安山岩改为泥土、原金块改为纵向橡木原木；新生成的金块不会在同一笔画中继续变成原木。未匹配的源状态保持原值。旧数字世界使用其实际 `numeric:ID[data=META]` 状态，不能与命名状态混用；空行、无效状态或布局不匹配会报告错误。

规则行带有列表代次。删除或追加改变列表后，尚在队列中的旧行事件会报告列表已改变，不能误改移动到原索引的另一条规则。

## 参数保存

模式、尺寸、偏移、形状、空心、替换规则及两个模式的目标保存在独立 Rust 配置的 `brush` 字段。复用观察状态的单个后台写入队列，锁内合并配置，保留 `views` 和其他功能字段；快速修改合并提交，退出时排空队列。画笔启用状态不持久化。

未完成或无效输入保留在当前面板并报告未保存，不写入新的无效设置。下次启动读取最后成功保存的有效设置。损坏设置或未知版本明确报告，不自动改写原文件；原有 `-resetPrefs` 仍只重置独立的 Rust 配置。

## 材质光标

各世界视图和四视图使用当前资源包的实际模型、纹理、透明通道和形状掩码显示悬停笔触。填充显示目标状态；替换沿用原版行为，以第一条规则的目标作为代表外观，实际候选仍执行整张规则表。Biome 显示草方块，并从独立候选会话读取目标修改后的真实整列 / 四格颜色及邻域；目标已相同时仍显示有效光标。

光标是透明背景的独立图层，使用各视图自己的相机和投影，透视准星绘制在材质光标上方；源拾取仍指向真实地形。光标不暂存修改、不发布源拾取，也不保存世界。鼠标离开、进入导航或按住 Alt / Ctrl 会撤回悬停材质；后台只保留最新请求，取消或过期结果不会重新显示。各视图共享同一逻辑设备上未变的图集纹理，各自保留相机和采样绑定；不同设备或 wgpu 实例不共享 GPU 资源。

缺少资源、目标格式错误或不支持的专用渲染沿用正式渲染器的错误及缺失材质诊断。光标不是已生成的完整编辑候选；需要源 BE 或其他附加载荷的状态仍受正式编辑流程约束。

## 大笔画与工作预算

普通范围替换、形状笔刷、连续填充 / 替换笔画、连通填充和 Biome 笔画使用预算化入口，不再按 4096 格拒绝整笔操作。默认编辑任务预算为 256 MiB，可在编辑面板输入正整数 MiB；该值属于本次运行，不写入笔刷参数配置。它估算本次新增选区、源解码、候选证明及暂存构建的工作集，不是已有会话、全部历史或整个进程的硬内存上限。

拖画只记录线段，后台按整数路径补点；选区以区段位图合并去重，空心仍在整笔并集后计算。普通填充逐区块读取，每 4096 格检查取消并报告工作进度；连通填充只读取实际可达和边界格，按预算管理源缓存。Biome 按区块投影到原来的整列或四格存储单元。所有源复核通过后，在私有候选会话中构建整组结果，最后一次发布；后段出错或取消不会留下部分暂存。整笔仍作为一次撤销和重做，后台历史操作可以取消。

材质光标沿用真实资源模型，生成前估算方块与几何工作量；超预算正常报告错误。进度展示已检查格、实际选区格、候选变化和完成的切片数量，候选准备并不表示已经写入世界。

## 当前边界

笔刷每轴尺寸仍为 1..512。完整剪贴板捕获、结构变换 / 交换以及桌面完整克隆 / 移动也已接入任务预算，见 `MIGRATION.md`。插件快照、差异预检和声明式依赖步骤也已接入任务预算，详见 `MIGRATION.md`；旧方块专用克隆 / 移动 API 和切片检查统一复用现有编辑工作集预算，不再另设 4096 格或 64×64 上限。选框只检查几何坐标，实际任务负责检查工作集。笔刷不自动创建缺失区块 / 区段，不猜测数字与命名注册表映射，也不丢弃目标已有的方块实体载荷。需要附加载荷的替换应使用结构事务。真实窗口大笔画、真实存档性能及游戏保存重载验收仍待完成。

实现依据为原版 `7c13c16^` 的 `editortools/brush/__init__.py`、`brush/modes.py`、`selection/hollow.py`、`operations/block_fill.py` 及 `tool_settings.py`；原版实际形状列表由 `brush/shapes.py::getShapes` 提供。
