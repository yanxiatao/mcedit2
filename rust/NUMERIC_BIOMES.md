# 旧数字生物群系颜色

数字 ID 保持数字，不转换成现代名称，也不修改世界的注册表或 NBT。

选择已有 1.8—1.12 客户端渲染映射时，颜色来源为原版 MCEdit2 的 61 项静态气候表。数据逐项迁自 `9fd9e91dc292c8405e4b5247774e1cc4f9d5dbe8:src/mceditlib/anvil/biomes.csv`，范围为缺少 DataVersion 的旧区块及 DataVersion 0—1343。草、普通树叶、藤蔓等使用资源包实际的 256×256 草 / 叶色图。云杉与桦木继续使用既有固定颜色规则。

内置表按原版 MCEdit2 逐列取色，不套现代八角点采样和默认五格混色。水保留资源纹理本色。它代表 MCEdit2 的静态预览规则，不是运行中游戏的模组注册表；不涵盖原版游戏的全部特殊颜色提供器。未定义数字、版本不符、未知高度及缺少色图会输出诊断并显示洋红缺失色，不借用其他群系或默认平原。

资源包可在目录或 ZIP / JAR 中提供 `assets/mcedit2/biomes/numeric.json`。按现有包顺序，较高层的文件整份替换较低层表，不合并遗漏条目。无效表直接使本次资源加载报错。

```json
{
  "format": 1,
  "source": "实际导出或人工确认的来源说明",
  "versions": {"minimum": 2586, "maximum": 2586, "unversioned": false},
  "blend_radius": 1,
  "entries": [
    {
      "id": 70000,
      "name": "自定义生物群系",
      "temperature": 0.5,
      "rainfall": 0.5,
      "water_color": 4159204,
      "grass_color": 1193046,
      "foliage_color": 6636321
    }
  ]
}
```

`minimum`、`maximum` 是实际区块 DataVersion 的闭区间；`unversioned` 明确控制是否接收没有版本字段的旧数据。`blend_radius` 为 0—7，表示同高度 `(2r+1)²` 个真实数字样本的 RGB 整数平均；0 表示直接取色。混色邻域不完整时显示缺失色。旧三维数字容器按当前已绑定高度的真实单元读取，不冒充现代模糊采样。

条目必须有唯一的整数 `id`、名称、有限温度、0—1 湿度及 24 位 RGB 水色。草色与叶色可省略或为 null，此时使用表中气候与资源包色图；提供时直接使用所给 RGB。文件按现有 2 MiB 字节预算读取，不另设条目数上限。刷子候选列表显示已加载表的名称与数字，表示可选颜色定义，不证明该 ID 已注册在当前世界。

真实候选会话和独立结构预览使用各自实际的数字载荷及版本；修改 biome 后，受影响网格和颜色层重新生成。未知模组运行时注册表、其他版本规则和实际游戏重载验收仍需后续接入。
