# 2026-11-14 审查修复

对应 rust-iced-rewrite 的基线提交 e4396065f35c44ded9e36a687ace4f2fa68c62f1。本轮修改集中在审查发现的行为问题及其清理，不发布环境或应用。

- 插件生命周期：Unix 为一次性宿主和持久工具建立独立进程组，超时、取消及宿主退出时回收所属后代，解除继承管道造成的等待；Windows 沿用 Job 管理。回归检查会实际启动带后代的宿主。
- 构建与 CI：修复 RustPython 0.5 与 libc 的 POSIX_SPAWN_SETSID 类型不兼容，暂锁 libc 0.2.186；上游适配后可解除该约束。源码 push / PR 触发 Linux 和 Windows 检查，使用锁文件，Linux 安装 libffi-dev。删除 CI 哨兵文件。
- 测试组织：删除 Category 枚举及 156 个手写分派，独立行为直接注册标准 Rust harness，取消入口数量上限。配置环境变量的检查使用独立子进程；GPU 和真实安装资源检查明确标记忽略。
- 模型：移除未接入产品发现流程的测试专用 glTF 解码器、空类型表和生产选择分支，保留正式 OBJ / MTL 加载与材质逻辑。
- 工作预算：将所选预算传到结构读取、编码、保存、Region 创建、实体联合保存及事务提交、回滚、历史快照。Region 格式位宽与任务内存预算分开验证；源文件身份和保存后磁盘头改为流式摘要核验。保留单区块解压、类型、坐标、版本、不可变备份及来源校验。
- 自定义方块实体：用户明确提供完整 NBT 时可保留未知注册关系；内置已知不兼容关系仍拒绝，不为未知类型猜测默认载荷。
- 分配前保护：level.dat 及目录数据包 JSON 的读取器直接接收大小上限，读取前核对并有界读取。
- Linux 自动预算：同时读取主机可用内存和当前 cgroup / 可见祖先的剩余限额，支持 v1 / v2。
- 视图范围：前后端共用体积与内存验证，取消固定 64×64×48 边长门槛，保留地址表示限制。
- 清理：缓存容量检查实际触发条目和体素淘汰；Open 只取消一次网格任务、递增一次版本；删除无调用的内部转发与重复检查。
- 保存与配置：普通保存改为按钮确认，删除区块仍需明确口令；无效可选配置在所属区域报告，使用临时会话设置，并阻止自动持久化覆盖原配置。
