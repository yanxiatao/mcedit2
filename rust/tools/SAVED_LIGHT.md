## 已核实的合同

现代 `LayerLightSectionStorage.updateSectionStatus` 为非空气段及其 26 个邻段维护光照层。`ChunkSerializer` 省略空的齐次零 DataLayer；`DataLayer.isEmpty` 仅在没有数组且默认值为零时成立，并非扫描后把任意零数组都省略。天空和方块层独立保存，纯光照段也是有效来源。

`BlockLightSectionStorage.getLightValue` 在没有光照层时返回零。`SkyLightSectionStorage.getLightValue` 在已分配段读取实际层；未分配段沿同列向上找到首个实际层，以其底行解释当前列。高于该列全部分配来源或无上方来源时返回 15。因而不能把任意缺失 SkyLight 数组直接当作零，尤其不能把暂存新方块当作原存档已分配光照的证明。

Rust 渲染采样只在准确 3465 / 3955、`isLightOn != 0` 且 `Status` 为 `full` / `minecraft:full` 时解释这些省略值。分配来源取真实基底段里实际引用的非空气状态，以及实际保存的光照数组；不采用未使用的调色板项或暂存 overlay。解释所需的邻块尚未读取时，由现有 Reader 补读，取消与读取错误正常传递。并行完整区块路径沿同一 SharedRegionBatch 读取。邻域不改变用户请求范围的来源计数。

1.12.2 的 `aye` 保存、恢复 `HeightMap`；`axw.c(BlockPos)` 使用 `height[z*16+x]` 判断天空可见。整个 Section 缺失时，方块光为零，天空光依据该保存高度图为 0 或 15；Section 存在但通道缺失时不臆造数组。`amu.b(LightType, BlockPos)` 将负 Y 归至零，高于存储高度时采用 `ana` 的天空 15 / 方块 0 默认值。无天空维度在渲染表中不使用天空通道。

1.12.2 的 `ayn` 将主世界、下界、末地分别绑定 `ayp`、`ayo`、`ays`。主世界沿用 `aym` 的最低亮度 0 和天空；`ayo` 使用最低亮度 0.1、无天空；`ays` 沿用最低亮度 0、无天空并使用末地分支。不把旧自定义维度名称套成任意原版提供者。

原始 `Chunk.light.sample` 和方块查询仍只返回真实保存数组及缺失标记。解释后的渲染采样单独捕获到体素 / 切片，不改 NBT、不重算光照。其他版本、未完成区块及未核实定义继续保留原始值，缺少必要通道时正常报告错误。

## 蜘蛛眼睛与加色来源

本项仍只静态读取上表准确客户端，没有启动游戏、编译参照类或执行 Rust 检查。1.20.1 `ftm` 与 1.21.1 `gpc` 使用实际 `textures/entity/spider_eyes.png`，复用身体模型和姿态。1.20.1 `fss` 在眼睛层传入 15728640，但两版 `rendertype_eyes.vsh` 均不采样光照贴图；不能将该参数当作依赖天空光的普通源面。固定不读光照单独编码，父对象继承不覆盖。

1.20.1 `fkf` 的 eyes 类型绑定 `fke.d`，`fke.P()` 明确调用 ONE / ONE 混合；1.21.1 `gfh.p(ResourceLocation)` 默认同样传入加色透明状态。类型使用 COLOR_WRITE，保留深度比较而不写深度，默认启用剔除。两版 `rendertype_eyes.fsh` 将采样 RGB 直接乘顶点色和调制值，没有按 Alpha 丢弃或预乘。因此编辑器加色管线独立于普通透明管线，RGBA8 目标仍在每次混合后按实际格式量化 / 饱和。

1.12.2 `cck` 使用 ONE / ONE、关闭 Alpha Test，并以 `!isInvisible()` 选择 depthMask。其传入光照坐标为 `61680 % 65536` 与 `61680 / 65536`，即 X=61680 / Y=0；经原生 lightmap 边缘 clamp 后对应 block=15 / sky=0。该旧层仍取光照表，与现代不读取光照的层分开。独立结构预览明确使用不依赖世界贴图的亮度，不借世界光照冒充预览来源。

眼睛层不因身体 Invisible 就停止提交。世界与结构预览先按实际身体范围准备名称，再保留明确允许隐形绘制的层；普通身体不因此显示。加色拾取读取纹理与顶点 RGB 的实际贡献，Alpha=0 不是丢弃条件，黑色无贡献区域不创造命中。

加色的 RGB 贡献不能用任意背景上的普通直通 Alpha 图片表示。CPU / GPU 对含加色材质的世界画面先在自身颜色目标绘制实际天空，再执行同一材质顺序；天空端点与独立后景共享日光与原版量化，深度仍从空值开始。其他画面继续透明提交。关闭材质光照时保留日光参数和缓存身份；加色不会被误乘纹理 Alpha，也不会随关闭材质光照而丢失背景来源。
